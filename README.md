Standard Numeric Format
الـ Standard Numeric Format هو الطريقة القياسية لكتابة الأرقام وعرضها بشكل واضح ومنظم.

(أمثلة):

1234.56 → Standard numeric format

1,234.56 → رقم مع فاصل الآلاف

0.25 → عدد عشري

-1500 → عدد سال
